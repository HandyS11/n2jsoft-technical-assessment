# Wrap-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the delivery what an evaluator meets first: the `webapi` exports its logs, traces and metrics to the
Aspire dashboard; the three lists page through one shared component; the redundant `prestart` script and stale local
branches are gone; a fresh clone runs as documented; "Mes Notes" opens with an overview and a traceability table.

**Architecture:** OpenTelemetry is wired in the composition root only (`WebApi/Telemetry/TelemetryExtensions.cs`,
`AddTelemetry()` first in `Program.cs`): ASP.NET Core and runtime instrumentation, `/health` filtered out of traces,
Npgsql spans and metrics from the Aspire integration already registered by `AddInfrastructure`, OTLP export only when
`OTEL_EXPORTER_OTLP_ENDPOINT` is set. The acceptance tier proves it with an in-memory exporter added to a dedicated
`WebApplicationFactory`. The frontend's pagination bar becomes `core/pagination.component.ts`, fed the `PagedList`
each page already has.

**Tech Stack:** .NET 10 (SDK 10.0.401) minimal APIs, OpenTelemetry .NET 1.19, EF Core 10 + Npgsql (Aspire 13.6.1),
xUnit v3 on Microsoft.Testing.Platform, Shouldly, Reqnroll + Testcontainers, Aspire.Hosting.Testing + Playwright,
Angular 22 + Nx 23 + Vitest.

**Spec:** [docs/superpowers/specs/2026-10-11-wrap-up-design.md](../specs/2026-10-11-wrap-up-design.md)

## Verified during planning

Tasks 1 and 2 were built in a throwaway worktree of this repository (`/tmp/n2j-spike-wrapup`, branch
`spike/wrap-up`), with the repo's analyzer set (warnings as errors) and a real Postgres 18.3, then passed through
`jb cleanupcode` (no change). Every listing below is copied from that worktree:

- Unit tests: 166 passed (2 new). Acceptance: 212 passed before the last two scenarios were added; the
  `TelemetryFeature` class alone then passed 4 of 4 in 6 s, factory disposal included. Frontend: 171 passed (7 new),
  lint and build clean.
- **Mutation checks:** without `AddTelemetry()` both trace scenarios fail; with the filter removed the health outline
  fails; with an ordinal (case-sensitive) filter only its `/HEALTH` example fails; a `throw` in the exporter branch makes
  the unreachable-collector scenario fail, so that scenario does run `UseOtlpExporter()`.

The spec's three risks hold:

1. **Npgsql telemetry.** `Aspire.Npgsql.EntityFrameworkCore.PostgreSQL` 13.6.1 calls `WithTracing(… AddNpgsql())` and
   `WithMetrics(… AddMeter("Npgsql"))` on the same OpenTelemetry builder: database spans (source `Npgsql`, kind
   `Client`) are recorded under the server span with no extra code, and the `Npgsql` meter is already on. **No Npgsql
   meter is added in `AddTelemetry`.**
2. **In-memory exporter under `WebApplicationFactory`.** `ConfigureTestServices(services =>
   services.AddOpenTelemetry().WithTracing(t => t.AddInMemoryExporter(…)))` joins the API's own tracer provider: the
   API's instrumentation and `/health` filter apply. The server span sometimes ends after the client has read the
   response, hence the bounded polling in the steps.
3. **`prestart` removal.** With `frontend/node_modules` deleted and `prestart` removed, `dotnet run --project
   tools/N2JSoft.Aspire` (default profile) installs the packages itself (`AddJavaScriptApp` creates an installer
   resource) and `nx serve` starts. The `http` launch profile refuses to start without
   `ASPIRE_ALLOW_UNSECURED_TRANSPORT=true`; the default (https) profile is the one the README documents.

Also seen: the AppHost logs "The ASP.NET Core developer certificate is not trusted" and "No trusted Aspire development
certificate was found" on a machine without a trusted dev certificate, and still runs.

## Spec deviations (decided while planning)

- **Server spans are matched by `url.path`, not by route.** Their `http.route` is the route template,
  `/v{version:apiVersion}/users/` (versioned group, trailing slash), which is right for low-cardinality grouping in the
  dashboard but not what a scenario names. The steps take the path (`/v1/users`).
- **The health scenario is an outline over `/health` and `/HEALTH`**: routing is case-insensitive, so the filter is
  too (`StringComparison.OrdinalIgnoreCase`, which CA1307 asks to be explicit anyway).
- **A third scenario, *The API keeps answering when its telemetry cannot be exported*:** the only test that runs the
  OTLP branch (endpoint `http://127.0.0.1:9`, where nothing listens).
- **The "no span" step reads after waiting for a later request's span** (`/health`, then `/v1/users`): a negative
  assertion needs something to wait for.
- **`RecordedSpans`** (a locked `Collection<Activity>`) holds the exported spans: the exporter adds from server threads
  while a step reads.
- **Telemetry step methods that read no instance state are `static`** (CA1822); Reqnroll binds static methods.
- **The dev certificate is documented in "Mes Notes"** (Tranche 5), not under « Prérequis techniques », which is the
  subject's own text.

  namespace AcceptanceTests.Support;

  /// <summary>The exporter adds spans from the server's threads while a step reads them: both go through a lock.</summary>
  public sealed class RecordedSpans : Collection<Activity>

      public Activity[] Snapshot()

  using System.Diagnostics;
  using AcceptanceTests.Support;
  using Reqnroll;

  namespace AcceptanceTests.StepDefinitions;

  /// <summary>
  /// Server spans are found by their path: their <c>http.route</c> is the route template
  /// (<c>/v{version:apiVersion}/users/</c>), the same for every version.
  /// </summary>
  [Binding]
  public sealed class TelemetrySteps(ApiDriver api)
  {
      /// <summary>The server span ends once the response is written, possibly after the client has read it.</summary>
      private static readonly TimeSpan SpanTimeout = TimeSpan.FromSeconds(5);

      [Given("the API records its traces")]
      public void GivenTheApiRecordsItsTraces()
      {
          TestEnvironment.RecordedSpans.Clear();
          api.UseTelemetryRecording();
      }

      [Given("the API exports its telemetry to a collector that does not answer")]
      public void GivenTheApiExportsItsTelemetryToACollectorThatDoesNotAnswer()
      {
          api.UseUnreachableCollector();
      }

      [Then("the request to {string} is traced as a server span with the status {int}")]
      public static async Task ThenTheRequestIsTracedAsAServerSpanAsync(string path, int status)
      {
          var span = await WaitForServerSpanAsync(path);

          span.GetTagItem("http.response.status_code").ShouldBe(status);
      }

      [Then("the trace of the request to {string} contains a database span")]
      public static async Task ThenTheTraceContainsADatabaseSpanAsync(string path)
      {
          var span = await WaitForServerSpanAsync(path);

          TestEnvironment.RecordedSpans.Snapshot()
              .ShouldContain(other => other.TraceId == span.TraceId && other.Source.Name == "Npgsql",
                  $"the trace of {path} has no Npgsql span");
      }

      /// <summary>Run after waiting for a later request's span: the earlier request's span would have ended by then.</summary>
      [Then("no server span is recorded for the path {string}")]
      public static void ThenNoServerSpanIsRecordedForThePath(string path)
      {
          TestEnvironment.RecordedSpans.Snapshot().ShouldNotContain(span => IsServerSpanFor(span, path));
      }

      private static async Task<Activity> WaitForServerSpanAsync(string path)
      {
          var waited = Stopwatch.StartNew();
          while (true)
          {
              var span = Array.Find(TestEnvironment.RecordedSpans.Snapshot(), span => IsServerSpanFor(span, path));
              if (span is not null)
              {
                  return span;
              }

              if (waited.Elapsed > SpanTimeout)
              {
                  throw new ShouldAssertException($"No server span for {path} within {SpanTimeout}.");
              }

              await Task.Delay(TimeSpan.FromMilliseconds(50));
          }
      }

      private static bool IsServerSpanFor(Activity span, string path)
      {
          return span.Kind == ActivityKind.Server && (string?)span.GetTagItem("url.path") == path;
      }
  }
  ```

  using OpenTelemetry;
  using OpenTelemetry.Logs;
  using OpenTelemetry.Metrics;
  using OpenTelemetry.Trace;

  namespace WebApi.Telemetry;

  internal static class TelemetryExtensions
  {
      public static IHostApplicationBuilder AddTelemetry(this IHostApplicationBuilder builder)
      {
          builder.Logging.AddOpenTelemetry(options =>
          {
              options.IncludeFormattedMessage = true;
              options.IncludeScopes = true;
          });

          // Database spans and metrics come from the Aspire Npgsql integration (AddInfrastructure).
          var telemetry = builder.Services.AddOpenTelemetry()
              .WithTracing(tracing => tracing.AddAspNetCoreInstrumentation(options =>
                  // Health probes would drown the requests that matter.
                  options.Filter = context =>
                      !context.Request.Path.StartsWithSegments("/health", StringComparison.OrdinalIgnoreCase)))
              .WithMetrics(metrics => metrics.AddAspNetCoreInstrumentation().AddRuntimeInstrumentation());

          // Aspire sets the endpoint; without it (tests, a bare dotnet run) nothing is exported.
          if (!string.IsNullOrWhiteSpace(builder.Configuration["OTEL_EXPORTER_OTLP_ENDPOINT"]))
          {
              telemetry.UseOtlpExporter();
          }

          return builder;
      }
  }
  ```
