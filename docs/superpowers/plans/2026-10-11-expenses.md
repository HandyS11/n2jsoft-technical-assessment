# Expenses Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add expenses to expense reports. An expense has a date within the report's month, a description, an amount
and a billing address. It is refused at the user's monthly quota, stays editable, and is deleted logically. It is
managed from the report page, which lists the expenses 5 at a time and shows the report's count and total.

**Architecture:** `Expense` entity and `BillingAddress` value object in `Domain`; the report-month and quota rules
live in `Expense.Create` / `Update`, which receive the report, the user and the live expense count. Every expense
write runs in one transaction that locks the report row (`FOR UPDATE`) then the user row (`FOR SHARE`), so the
quota counted holds until the save and a concurrent user deletion is seen. One store per feature (`IExpenseStore`),
one handler per write; routes nested under `/v1/expense-reports/{reportId}/expenses`. The database cascades a report
deletion to its expenses.

**Tech Stack:** .NET 10 (SDK 10.0.401) minimal APIs, EF Core 10 + Npgsql (Aspire 13.6.1), xUnit v3 on
Microsoft.Testing.Platform, Shouldly, NSubstitute, Reqnroll + Testcontainers + Respawn, Aspire.Hosting.Testing +
Playwright, Angular 22 + Nx 23 + Vitest.

**Spec:** [docs/superpowers/specs/2026-10-11-expenses-design.md](../specs/2026-10-11-expenses-design.md)

## Verified during planning

The whole slice was built in a throwaway worktree of this repository, with the repo's analyzer set (warnings as
errors) and a real Postgres 18.3, then passed through `jb cleanupcode` (no change). Every listing in this plan is
copied from that worktree:

- Unit tests: 164 passed (57 new). Acceptance: 202 passed (70 new). Frontend: 154 passed (lint and build clean).
  End-to-end: the 4 new journeys and the 4 existing expense report journeys passed.

The spec's three risks hold:

1. **Nested complex property.** `BillingAddress` (nullable `StoreName`) holding `Address` maps with
   `ComplexProperty` inside `ComplexProperty`; the migration creates `BillingAddress_StoreName` (nullable,
   `character varying(100)`) and `BillingAddress_Address_Street` / `_PostalCode` / `_City`. Projections read
   `null` back for a missing store.
2. **Locks.** `FromSql(… FOR UPDATE)` on `expense_reports` then the existing `FOR SHARE` on `users`, inside
   `ITransactionRunner`: an expense addition and a report `DELETE` both wait for a held report lock, then proceed
   (no deadlock). Two concurrent HTTP additions at quota − 1 always give one `201` and one `422`, so this race is
   tested with real concurrent requests.
3. **Cascade without navigation.** `HasOne<ExpenseReport>().WithMany().HasForeignKey(…).OnDelete(Cascade)` generates
   `ON DELETE CASCADE`; deleting a report through EF removes its expenses, soft-deleted ones included, without
   loading them.

Also checked: `[Range(typeof(decimal), "0.01", "999999.99", ParseLimitsInInvariantCulture = true, …)]` on a
`decimal?` answers `400`; a date that is not `yyyy-MM-dd` answers `400`; an empty report's `Sum` is `0`, not an
error.

## Spec deviations (decided while planning)

- **`IExpenseReportStore.ExistsAsync(Guid id)`** answers the expenses list's "does the report exist" check; the spec
  said `GetDetailsAsync`, which now runs two queries for counts and the user.
- **`ExpenseReportDetails` reads the user in a second query.** `IgnoreQueryFilters()` is all-or-nothing in a query:
  in the same query it would also count deleted expenses.
- **`ExpenseReportDetails.From(report, user)`**: the report just created has no expense, a total of 0, the user's
  quota, and is not read-only.
- **The frontend sends `If-Match` from the `version` in the body**, like `UsersApi.update`; `ExpensesApi.get` returns
  the body only (the spec said "body and `ETag`").
- **The report page's delete button reads "Supprimer la note de frais"**, so the rows' *Supprimer* buttons stay
  unambiguous.
- **Expense deletion confirmation:** `Supprimer la dépense « <description> » ?`. A failed *Modifier* load shows
  "Dépense introuvable." and reloads the list. A `404` on save says "Note de frais introuvable." in add mode and
  "Dépense introuvable." in edit mode; a `400` says "Les informations saisies sont invalides."
- **`If-Match` parsing moves to `Endpoints/EntityTags.cs`**; its error now says "an ETag returned by the API" rather
  than "the ETag of the user".
- **End-to-end journeys use October 2025**, with the user and the report created through the API, so the expected
  "mercredi 15 octobre 2025" does not depend on the day the tests run.

  another report; `409` / `412` concurrency on an expense; `422` with `code` for the three rules.
- Lock order in every expense write: report (`FOR UPDATE`), then user (`FOR SHARE`).
- English for code, Gherkin, commit messages and ProblemDetails. French for UI text and README "Mes Notes".
- Run commands from the repository root. `dtk dotnet …` is a token-saving wrapper; plain `dotnet …` works too.

## Review Focus

Inputs the spec implies but does not spell out, most likely to bite first. Each one has a test in the owning task.

1. **Two requests adding the last expense the quota allows at once** (double click, two tabs) must store one expense
   and refuse the other with `422 expense.quota_exceeded`, never store both. Pinned in Task 3 (concurrent HTTP
   scenario).
2. **The report's user deleted while an expense is being added** must make the addition wait, then refuse it with
   `422 expense_report.deleted_user`, storing nothing. Pinned in Task 3 (lock-wait scenario).
3. **An amount with a third decimal inside the range** (`12.345`) must be refused with `400`, never silently rounded
   to `12.35`. Pinned in Task 1 (unit) and Task 3 (acceptance outline).
4. **Editing an expense of a report already at its quota** must succeed: an edit cannot change the month's count.
   Pinned in Task 4 (unit and acceptance, quota 1).
5. **A report page left open while its user is deleted**: adding an expense there must show the French message and
   turn the page read-only, not leave a form that always fails. Pinned in Task 9 (page spec).

  using Domain.Exceptions;

  namespace Domain.ValueObjects;

  /// <summary>Where an expense was billed: an optional store name ("enseigne"), then a French postal address.</summary>
  public sealed record BillingAddress
  {
      public const int StoreNameMaxLength = 100;

      /// <param name="storeName">Trimmed; null when blank.</param>
      public BillingAddress(string? storeName, Address address)
      {
          ArgumentNullException.ThrowIfNull(address);
          var trimmedStoreName = string.IsNullOrWhiteSpace(storeName) ? null : storeName.Trim();
          if (trimmedStoreName?.Length > StoreNameMaxLength)
          {
              throw new InvalidValueException(nameof(storeName),
                  $"The store name must be at most {StoreNameMaxLength} characters.");
          }

          StoreName = trimmedStoreName;
          Address = address;
      }

      /// <summary>For EF Core only, which then sets the properties it loads.</summary>
      private BillingAddress()
      {
          Address = null!;
      }

      public string? StoreName { get; }
      public Address Address { get; }
  }

  ```csharp
  using Domain.Exceptions;
  using Domain.ValueObjects;

  namespace Domain.Entities;

  /// <summary>An expense of an expense report, editable at any time and deleted logically.</summary>
  public sealed class Expense
  {
      public const int DescriptionMaxLength = 50;
      public const decimal MinAmount = 0.01m;
      public const decimal MaxAmount = 999_999.99m;

      /// <summary>Only <see cref="Create" /> and EF Core, which then sets the properties it loads, build expenses.</summary>
      private Expense()
      {
      }

      public Guid Id { get; } = Guid.CreateVersion7();
      public Guid ExpenseReportId { get; private set; }

      /// <summary>Always within the report's month.</summary>
      public DateOnly Date { get; private set; }

      public string Description { get; private set; } = string.Empty;

      /// <summary>In euros, with at most two decimals.</summary>
      public decimal Amount { get; private set; }

      public BillingAddress BillingAddress { get; private set; } = null!;

      /// <summary>Set by a logical deletion; a deleted expense is hidden from every query and frees a quota slot.</summary>
      public DateTimeOffset? DeletedAt { get; private set; }

      /// <summary>Set by the database on every save, so an update made from an older copy of the expense can be detected.</summary>
      public uint Version { get; }

      /// <param name="liveExpenseCount">The report's expenses not deleted, counted while the report is locked.</param>
      /// <exception cref="ExpenseDateOutsideReportMonthException">The date is outside the report's month.</exception>
      /// <exception cref="ExpenseQuotaExceededException">The report already holds the user's monthly quota.</exception>
      public static Expense Create(
          ExpenseReport report,
          User user,
          int liveExpenseCount,
          DateOnly date,
          string description,
          decimal amount,
          BillingAddress billingAddress)
      {
          ArgumentNullException.ThrowIfNull(report);
          ArgumentNullException.ThrowIfNull(user);
          if (user.Id != report.UserId)
          {
              throw new ArgumentException("The user must be the report's.", nameof(user));
          }

          var trimmedDescription = CheckDetails(report, date, description, amount, billingAddress);
          if (liveExpenseCount >= user.MonthlyExpenseQuota)
          {
              throw new ExpenseQuotaExceededException(user.Id, user.MonthlyExpenseQuota);
          }

          var expense = new Expense
          {
              ExpenseReportId = report.Id
          };
          expense.Apply(date, trimmedDescription, amount, billingAddress);
          return expense;
      }

      /// <summary>Checks every detail before changing any, so a rejected update leaves the expense as it was.</summary>
      /// <exception cref="ExpenseDateOutsideReportMonthException">The date is outside the report's month.</exception>
      public void Update(
          ExpenseReport report,
          DateOnly date,
          string description,
          decimal amount,
          BillingAddress billingAddress)
      {
          ArgumentNullException.ThrowIfNull(report);
          if (report.Id != ExpenseReportId)
          {
              throw new ArgumentException("The report must be the expense's.", nameof(report));
          }

          Apply(date, CheckDetails(report, date, description, amount, billingAddress), amount, billingAddress);
      }

      public void Delete(DateTimeOffset now)
      {
          DeletedAt ??= now;
      }

      /// <summary>The values first (400), then the report-month rule (422). Returns the trimmed description.</summary>
      private static string CheckDetails(
          ExpenseReport report,
          DateOnly date,
          string description,
          decimal amount,
          BillingAddress billingAddress)
      {
          ArgumentNullException.ThrowIfNull(billingAddress);
          var trimmedDescription = Text.Required(description, DescriptionMaxLength);
          if (amount is < MinAmount or > MaxAmount)
          {
              throw new InvalidValueException(nameof(amount),
                  $"The amount must be between {MinAmount} and {MaxAmount}.");
          }

          if (decimal.Round(amount, 2) != amount)
          {
              throw new InvalidValueException(nameof(amount), "The amount must have at most two decimals.");
          }

          if (!report.Period.Contains(date))
          {
              throw new ExpenseDateOutsideReportMonthException(date, report.Period);
          }

          return trimmedDescription;
      }

      private void Apply(DateOnly date, string description, decimal amount, BillingAddress billingAddress)
      {
          Date = date;
          Description = description;
          Amount = amount;
          BillingAddress = billingAddress;
      }
  }
  ```

  using System.Globalization;
  using Microsoft.Net.Http.Headers;

  namespace WebApi.Endpoints;

  /// <summary>A resource's version (Postgres xmin) as a strong ETag ("\"7\""), and back from If-Match.</summary>
  internal static class EntityTags
  {
      public static string Of(uint version)
      {
          return new EntityTagHeaderValue($"\"{version}\"").ToString();
      }

      /// <summary>Null for no If-Match or "*" (any version); a 400 for a value that is not one of our ETags.</summary>
      public static uint? ExpectedVersionOf(string? ifMatch)
      {
          if (string.IsNullOrEmpty(ifMatch) || ifMatch == "*")
          {
              return null;
          }

          if (EntityTagHeaderValue.TryParse(ifMatch, out var entityTag)
              && !entityTag.IsWeak
              && uint.TryParse(entityTag.Tag.AsSpan(1, entityTag.Tag.Length - 2), CultureInfo.InvariantCulture,
                  out var version))
          {
              return version;
          }

          throw new BadHttpRequestException("If-Match must be \"*\" or an ETag returned by the API.");
      }
  }

  using Domain.Entities;
  using Domain.Exceptions;

  namespace Application.Expenses;

  internal static class ExpenseChanges
  {
      /// <summary>
      /// The first reads of every expense change, inside its transaction and always in this order (report, then user),
      /// so two changes cannot deadlock. The report stays locked until the commit: changes to its expenses run one after
      /// the other, and a quota counted here stays true until the save. A deletion or quota change of the user waits too.
      /// </summary>
      /// <exception cref="NotFoundException">The report is unknown.</exception>
      /// <exception cref="DeletedUserException">The report's user is deleted: its expenses can no longer change.</exception>
      public static async Task<(ExpenseReport Report, User User)> LockReportAndUserAsync(
          IExpenseReportStore expenseReportStore,
          IUserStore userStore,
          Guid reportId,
          CancellationToken cancellationToken)
      {
          var report = await expenseReportStore.FindLockedAsync(reportId, cancellationToken).ConfigureAwait(false)
                       ?? throw new NotFoundException("ExpenseReport", reportId);
          // Null only for a deleted user: a report's user cannot be unknown (foreign key, users never removed).
          var user = await userStore.FindLockedAsync(report.UserId, cancellationToken).ConfigureAwait(false)
                     ?? throw new DeletedUserException(report.UserId);
          return (report, user);
      }
  }

  using Application.ExpenseReports;
  using Application.Persistence;
  using Application.Users;
  using Domain.ValueObjects;

  namespace Application.Expenses.Commands;

  /// <param name="ExpectedVersion">
  /// The version the client read; when given, the update is rejected if the expense changed since. Null overwrites
  /// whatever is stored.
  /// </param>
  public sealed record UpdateExpenseCommand(
      Guid ReportId,
      Guid Id,
      DateOnly Date,
      string Description,
      decimal Amount,
      BillingAddress BillingAddress,
      uint? ExpectedVersion = null);

  /// <summary>Never checks the quota: the date stays within the report's month, so the month's count cannot change.</summary>
  public sealed class UpdateExpenseHandler(
      ITransactionRunner transactions,
      IExpenseReportStore expenseReportStore,
      IUserStore userStore,
      IExpenseStore expenseStore)
  {
      public Task HandleAsync(UpdateExpenseCommand command, CancellationToken cancellationToken)
      {
          return transactions.RunAsync(
              async token =>
              {
                  var (report, _) = await ExpenseChanges
                      .LockReportAndUserAsync(expenseReportStore, userStore, command.ReportId, token)
                      .ConfigureAwait(false);
                  var expense = await expenseStore.FindAsync(report.Id, command.Id, token).ConfigureAwait(false)
                                ?? throw new NotFoundException("Expense", command.Id);
                  if (command.ExpectedVersion is { } expectedVersion && expectedVersion != expense.Version)
                  {
                      throw new ConcurrencyConflictException("Expense", command.Id);
                  }

                  expense.Update(report, command.Date, command.Description, command.Amount, command.BillingAddress);
                  await expenseStore.SaveChangesAsync(token).ConfigureAwait(false);
              },
              cancellationToken);
      }
  }

  import { inject, Injectable } from '@angular/core';
  import { Observable } from 'rxjs';
  import { PagedResult } from '../../core/paged-result';
  import { ExpenseDetails, ExpenseSummary, SaveExpense } from './expense';

  function expensesUrl(reportId: string): string {
    return `/api/v1/expense-reports/${reportId}/expenses`;
  }

  @Injectable({ providedIn: 'root' })
  export class ExpensesApi {
    private readonly http = inject(HttpClient);

    list(reportId: string, page: number, pageSize: number): Observable<PagedResult<ExpenseSummary>> {
      return this.http.get<PagedResult<ExpenseSummary>>(expensesUrl(reportId), { params: { page, pageSize } });
    }

    get(reportId: string, id: string): Observable<ExpenseDetails> {
      return this.http.get<ExpenseDetails>(`${expensesUrl(reportId)}/${id}`);
    }

    /** Refused with a 422 when the quota is reached, the date is outside the report's month or the user is deleted. */
    create(reportId: string, expense: SaveExpense): Observable<ExpenseDetails> {

      });
    }

    delete(reportId: string, id: string): Observable<void> {
      return this.http.delete<void>(`${expensesUrl(reportId)}/${id}`);

  import { HttpErrorResponse } from '@angular/common/http';
  import { Component, computed, effect, inject, input, output, signal, untracked } from '@angular/core';
  import {
    AbstractControl,
    NonNullableFormBuilder,
    ReactiveFormsModule,
    ValidationErrors,
    ValidatorFn,
    Validators,
  } from '@angular/forms';
  import { Observable } from 'rxjs';
  import { businessRuleCode } from '../../core/problem-details';
  import { ExpenseDetails, SaveExpense } from './expense';
  import { ExpensesApi } from './expenses.api';

  /**
   * The API's limits (Expense.DescriptionMaxLength, MinAmount, MaxAmount, BillingAddress.StoreNameMaxLength and the
   * address rules), checked here first for immediate feedback. The API stays the authority.
   */
  const descriptionMaxLength = 50;
  const minAmount = 0.01;
  const maxAmount = 999_999.99;
  const storeNameMaxLength = 100;
  const streetMaxLength = 200;
  const cityMaxLength = 100;
  const postalCodePattern = /^[0-9]{5}$/;
  /** A positive number with at most two decimals, as the API stores it. */
  const amountPattern = /^[0-9]+(\.[0-9]{1,2})?$/;

  const ruleMessages = new Map<string, string>([
    [
      'expense.quota_exceeded',
      "Le quota mensuel de dépenses de cet utilisateur est atteint : impossible d'ajouter cette dépense.",
    ],
    ['expense.date_outside_report_month', 'La date doit être comprise dans le mois de la note de frais.'],
    [
      'expense_report.deleted_user',
      "L'utilisateur de cette note de frais a été supprimé : elle est en lecture seule.",
    ],
  ]);

  /** Like Validators.required, but text made only of spaces is missing too: the API would trim it to nothing. */
  function requiredText(control: AbstractControl<string>): ValidationErrors | null {
    return control.value.trim() === '' ? { required: true } : null;
  }

  function twoDecimals(control: AbstractControl<number | null>): ValidationErrors | null {
    return control.value === null || amountPattern.test(String(control.value)) ? null : { decimals: true };
  }

  function hasStatus(error: unknown, ...statuses: number[]): boolean {
    return error instanceof HttpErrorResponse && statuses.includes(error.status);
  }

  type Field = 'date' | 'description' | 'amount' | 'storeName' | 'street' | 'postalCode' | 'city';

  /**
   * Adds an expense to a report or, given one to edit, changes it. Validators mirror the API's rules; the API's refusals
   * show in French.
   */
  @Component({
    selector: 'app-expense-form',
    imports: [ReactiveFormsModule],
    template: `
      <form [formGroup]="form" (ngSubmit)="save()" novalidate class="flex max-w-md flex-col gap-2">
        <h2 class="text-xl font-semibold">{{ expense() ? 'Modifier la dépense' : 'Nouvelle dépense' }}</h2>

        <label for="date">Date</label>
        <input id="date" type="date" [min]="firstDay()" [max]="lastDay()" formControlName="date" />
        @if (errorFor('date'); as message) {
          <p class="field-error text-sm text-red-700">{{ message }}</p>
        }

        <label for="description">Description</label>
        <input id="description" formControlName="description" />
        <p class="text-sm">{{ form.controls.description.value.length }}/{{ descriptionMaxLength }}</p>
        @if (errorFor('description'); as message) {
          <p class="field-error text-sm text-red-700">{{ message }}</p>
        }

        <label for="amount">Montant (€)</label>
        <input id="amount" type="number" min="0.01" max="999999.99" step="0.01" formControlName="amount" />
        @if (errorFor('amount'); as message) {
          <p class="field-error text-sm text-red-700">{{ message }}</p>
        }

        <label for="storeName">Enseigne (facultatif)</label>
        <input id="storeName" formControlName="storeName" />
        @if (errorFor('storeName'); as message) {
          <p class="field-error text-sm text-red-700">{{ message }}</p>
        }

        <label for="street">Rue</label>
        <input id="street" formControlName="street" />
        @if (errorFor('street'); as message) {
          <p class="field-error text-sm text-red-700">{{ message }}</p>
        }

        <label for="postalCode">Code postal</label>
        <input id="postalCode" formControlName="postalCode" inputmode="numeric" />
        @if (errorFor('postalCode'); as message) {
          <p class="field-error text-sm text-red-700">{{ message }}</p>

          <p role="alert">{{ message }}</p>
        }

          <button type="submit" [disabled]="saving()">{{ expense() ? 'Enregistrer' : 'Ajouter' }}</button>
          @if (expense()) {
            <button type="button" (click)="cancelled.emit()">Annuler</button>
          }
        </div>
      </form>
    `,
  })
  export class ExpenseFormComponent {
    readonly reportId = input.required<string>();
    readonly year = input.required<number>();
    /** 1 for January to 12 for December. */
    readonly month = input.required<number>();
    /** The expense to edit, as loaded; undefined to add one. */
    readonly expense = input<ExpenseDetails>();

    /** An expense was added or changed; the form is empty again, ready for the next one. */
    readonly saved = output<'created' | 'updated'>();
    readonly cancelled = output<void>();
    /** The API says the report changed (its user was deleted): the page should read it again. */
    readonly reportChanged = output<void>();

    private readonly api = inject(ExpensesApi);
    protected readonly descriptionMaxLength = descriptionMaxLength;
    protected readonly saving = signal(false);
    protected readonly error = signal<string | null>(null);
    /** "2025-10" for October 2025: the start of every date of the report's month. */
    private readonly monthPrefix = computed(() => `${this.year()}-${String(this.month()).padStart(2, '0')}`);
    protected readonly firstDay = computed(() => `${this.monthPrefix()}-01`);
    /** Day 0 of the next month is the last day of this one. */
    protected readonly lastDay = computed(() => {
      const lastDay = new Date(this.year(), this.month(), 0).getDate();
      return `${this.monthPrefix()}-${String(lastDay).padStart(2, '0')}`;
    });

    /** One of the report's month's days: "2025-10-15" starts with "2025-10-". Empty is left to Validators.required. */
    private readonly withinMonth: ValidatorFn = (control: AbstractControl<string>) => {
      if (control.value === '') {
        return null;
      }
      const isDate = /^[0-9]{4}-[0-9]{2}-[0-9]{2}$/.test(control.value);
      return isDate && control.value.startsWith(`${this.monthPrefix()}-`) ? null : { outsideMonth: true };
    };

    private readonly formBuilder = inject(NonNullableFormBuilder);
    protected readonly form = this.formBuilder.group({
      date: ['', [Validators.required, this.withinMonth]],
      description: ['', [requiredText, Validators.maxLength(descriptionMaxLength)]],
      amount: this.formBuilder.control<number | null>(null, [
        Validators.required,
        Validators.min(minAmount),
        Validators.max(maxAmount),
        twoDecimals,
      ]),
      storeName: ['', Validators.maxLength(storeNameMaxLength)],
      street: ['', [requiredText, Validators.maxLength(streetMaxLength)]],
      postalCode: ['', [Validators.required, Validators.pattern(postalCodePattern)]],
      city: ['', [requiredText, Validators.maxLength(cityMaxLength)]],
    });

    constructor() {
      // Switching between adding and editing starts over from the expense given (or an empty form).
      effect(() => {
        const expense = this.expense();
        untracked(() => this.fill(expense));
      });
    }

    protected errorFor(field: Field): string | null {
      const control = this.form.controls[field];
      if (control.valid || !control.touched) {
        return null;
      }
      if (control.hasError('required')) {
        return 'Ce champ est obligatoire.';
      }
      if (control.hasError('maxlength')) {
        return `${control.getError('maxlength').requiredLength} caractères au maximum.`;
      }
      switch (field) {
        case 'date':
          return 'Choisissez une date du mois de la note de frais.';
        case 'amount':
          return 'Indiquez un montant entre 0,01 et 999 999,99 €, avec au plus deux décimales.';
        default:
          return 'Le code postal doit comporter 5 chiffres.';
      }
    }

    protected save(): void {
      if (this.form.invalid) {
        this.form.markAllAsTouched();
        return;
      }
      const value = this.form.getRawValue();
      const body: SaveExpense = {
        date: value.date,
        description: value.description,
        amount: value.amount ?? 0,
        billingAddress: {
          storeName: value.storeName.trim() === '' ? null : value.storeName,
          street: value.street,
          postalCode: value.postalCode,
          city: value.city,
        },
      };
      const expense = this.expense();
      const request: Observable<unknown> =
        expense === undefined
          ? this.api.create(this.reportId(), body)
          : this.api.update(this.reportId(), expense.id, body, expense.version);

      this.saving.set(true);
      this.error.set(null);
      request.subscribe({
        next: () => {
          this.saving.set(false);
          // Adding again starts from an empty form; after an edit, the page leaves edit mode, which empties it.
          if (expense === undefined) {
            this.fill(undefined);
          }
          this.saved.emit(expense === undefined ? 'created' : 'updated');
        },
        error: (error: unknown) => {
          this.saving.set(false);
          this.error.set(this.saveErrorMessage(error));
          if (businessRuleCode(error) === 'expense_report.deleted_user') {
            this.reportChanged.emit();
          }
        },
      });
    }

    private fill(expense: ExpenseDetails | undefined): void {
      this.error.set(null);
      this.form.reset({
        date: expense?.date ?? '',
        description: expense?.description ?? '',
        amount: expense?.amount ?? null,
        storeName: expense?.billingAddress.storeName ?? '',
        street: expense?.billingAddress.street ?? '',
        postalCode: expense?.billingAddress.postalCode ?? '',
        city: expense?.billingAddress.city ?? '',
      });
    }

    private saveErrorMessage(error: unknown): string {
      const ruleMessage = ruleMessages.get(businessRuleCode(error) ?? '');
      if (ruleMessage !== undefined) {
        return ruleMessage;
      }
      if (hasStatus(error, 409, 412)) {
        return "Cette dépense a été modifiée entre-temps. Rechargez-la avant de l'enregistrer.";
      }
      if (hasStatus(error, 404)) {
        return this.expense() === undefined ? 'Note de frais introuvable.' : 'Dépense introuvable.';
      }
      if (hasStatus(error, 400)) {
        return 'Les informations saisies sont invalides.';
      }
      return "L'opération a échoué. Veuillez réessayer.";
    }
  }

  Replace `frontend/src/app/features/expense-reports/expense-report.page.ts` with the following. The page owns the

  import { CurrencyPipe, formatDate } from '@angular/common';
  import { HttpErrorResponse } from '@angular/common/http';
  import { Component, computed, inject, LOCALE_ID, signal } from '@angular/core';
  import { ActivatedRoute, Router, RouterLink } from '@angular/router';
  import { finalize } from 'rxjs';
  import { pagedList } from '../../core/paged-list';
  import { ExpenseDetails, ExpenseSummary, formatBillingAddress } from '../expenses/expense';
  import { ExpenseFormComponent } from '../expenses/expense-form.component';
  import { ExpensesApi } from '../expenses/expenses.api';
  import { confirmDeletion } from './confirm-deletion';
  import { ExpenseReportDetails } from './expense-report-details';
  import { ExpenseReportsApi } from './expense-reports.api';

  /** "Par lot de 5": the README's batch size. */
  const expensesPerPage = 5;

  function isNotFound(error: unknown): boolean {
    return error instanceof HttpErrorResponse && error.status === 404;
  }

  /** "1 dépense", "3 dépenses"; French keeps 0 singular. */
  function expenseCount(count: number): string {
    return `${count} ${count > 1 ? 'dépenses' : 'dépense'}`;
  }

  @Component({
    selector: 'app-expense-report-page',
    imports: [CurrencyPipe, ExpenseFormComponent, RouterLink],
    template: `
      <a routerLink="/expense-reports" class="underline">← Notes de frais</a>
      @if (error(); as message) {
        <p role="alert">{{ message }}</p>
      }
      @if (report(); as report) {
        <h1 class="my-4 text-2xl font-semibold">{{ report.title }}</h1>
        <p>Mois : {{ monthLabel() }}</p>
        <p>{{ countLabel() }}</p>
        <p>Total : {{ report.total | currency: 'EUR' }}</p>
        <button type="button" class="mt-4" [disabled]="deleting()" (click)="remove(report)">
          Supprimer la note de frais
        </button>

        <section class="my-8">
          @if (report.isReadOnly) {
            <p>L'utilisateur de cette note de frais a été supprimé : elle est en lecture seule.</p>
          } @else {
            <app-expense-form
              [reportId]="report.id"
              [year]="report.year"
              [month]="report.month"
              [expense]="editing()"
              (saved)="onSaved($event)"
              (cancelled)="editing.set(undefined)"
              (reportChanged)="loadReport()"
            />
          }
          @if (notice(); as message) {
            <p role="status" class="mt-2">{{ message }}</p>
          }
        </section>

        <section>
          <h2 class="mb-2 text-xl font-semibold">Dépenses</h2>

          }
          @if (expenses.actionFailed()) {

          }

                    <th>Date</th>
                    <th>Description</th>
                    <th>Montant</th>
                    <th>Adresse de facturation</th>
                    @if (!report.isReadOnly) {
                      <th>Actions</th>
                    }
                  </tr>
                </thead>
                <tbody>
                  @for (expense of page.items; track expense.id) {
                    <tr>
                      <td>{{ dateLabel(expense) }}</td>
                      <td>{{ expense.description }}</td>
                      <td>{{ expense.amount | currency: 'EUR' }}</td>
                      <td>{{ addressLabel(expense) }}</td>
                      @if (!report.isReadOnly) {
                        <td class="flex gap-2">

                          <button type="button" [disabled]="expenses.busy()" (click)="removeExpense(expense)">
                            Supprimer
                          </button>
                        </td>
                      }
                    </tr>
                  }
                </tbody>

  export default class ExpenseReportPage {
    private readonly api = inject(ExpenseReportsApi);
    private readonly expensesApi = inject(ExpensesApi);
    private readonly router = inject(Router);
    private readonly locale = inject(LOCALE_ID);
    private readonly id = inject(ActivatedRoute).snapshot.paramMap.get('id') ?? '';
    protected readonly report = signal<ExpenseReportDetails | undefined>(undefined);
    protected readonly error = signal<string | null>(null);
    protected readonly deleting = signal(false);
    /** The expense the form edits, as loaded; undefined while the form adds one. */
    protected readonly editing = signal<ExpenseDetails | undefined>(undefined);
    /** What the last change did ("Dépense ajoutée."), until the next one. */
    protected readonly notice = signal<string | null>(null);
    protected readonly expenses = pagedList((page) => this.expensesApi.list(this.id, page, expensesPerPage));

    /** "Octobre 2025", capitalised like the month in the title (the locale writes "octobre 2025"). */
    protected readonly monthLabel = computed(() => {
      const report = this.report();
      if (!report) {
        return '';
      }
      // The first day of the report's month, in local time.
      const label = formatDate(new Date(report.year, report.month - 1, 1), 'MMMM y', this.locale);
      return label.charAt(0).toUpperCase() + label.slice(1);
    });

    /** "3 dépenses sur 10 ce mois-ci"; a read-only report has no quota left to show. */
    protected readonly countLabel = computed(() => {
      const report = this.report();
      if (!report) {
        return '';
      }
      const count = expenseCount(report.expenseCount);
      return report.isReadOnly ? count : `${count} sur ${report.monthlyExpenseQuota} ce mois-ci`;
    });

    constructor() {
      this.loadReport();
    }

    /** Reads the report again: its counts and total after a change, or its read-only state. */
    protected loadReport(): void {
      this.api.get(this.id).subscribe({
        next: (report) => this.report.set(report),
        error: (error: unknown) =>
          this.error.set(
            isNotFound(error) ? 'Note de frais introuvable.' : 'Impossible de charger la note de frais.'
          ),
      });
    }

    /** "mercredi 15 octobre 2025". A "2025-10-15" date is read as a local day, never shifted by a time zone. */
    protected dateLabel(expense: ExpenseSummary): string {
      return formatDate(expense.date, 'EEEE d MMMM y', this.locale);
    }

    protected addressLabel(expense: ExpenseSummary): string {
      return formatBillingAddress(expense.billingAddress);
    }

    protected onSaved(change: 'created' | 'updated'): void {
      this.editing.set(undefined);
      this.notice.set(change === 'created' ? 'Dépense ajoutée.' : 'Dépense modifiée.');
      this.reloadExpenses();
    }

    protected edit(expense: ExpenseSummary): void {
      this.notice.set(null);
      this.expensesApi.get(this.id, expense.id).subscribe({
        next: (details) => this.editing.set(details),
        error: () => {
          // Most likely deleted meanwhile: the list shows what is left.
          this.notice.set('Dépense introuvable.');
          this.reloadExpenses();
        },
      });
    }

    protected removeExpense(expense: ExpenseSummary): void {
      if (!window.confirm(`Supprimer la dépense « ${expense.description} » ?`)) {
        return;
      }
      this.notice.set(null);
      if (this.editing()?.id === expense.id) {
        this.editing.set(undefined);
      }
      // Whether it worked or not, the counts and the read-only state may have changed.
      this.expenses.run(this.expensesApi.delete(this.id, expense.id).pipe(finalize(() => this.loadReport())));
    }

    protected remove(report: ExpenseReportDetails): void {
      if (!confirmDeletion(report.title)) {
        return;
      }
      this.deleting.set(true);
      this.error.set(null);
      this.api.delete(report.id).subscribe({
        next: () => {
          void this.router.navigateByUrl('/expense-reports');
        },
        error: (error: unknown) => {
          // Deleted meanwhile (another tab): it is gone, as asked.
          if (isNotFound(error)) {
            void this.router.navigateByUrl('/expense-reports');
            return;
          }
          this.deleting.set(false);
          this.error.set('La suppression a échoué. Veuillez réessayer.');
        },
      });
    }

    private reloadExpenses(): void {
      this.expenses.load(this.expenses.page()?.page ?? 1);
      this.loadReport();
    }
  }

      {
          var reportId = await CreateReportAsync("Karim");
          await AddExpenseThroughTheApiAsync(reportId, "2025-10-01", "Hôtel");
          await AddExpenseThroughTheApiAsync(reportId, "2025-10-02", "Train");
          await Page.GotoAsync($"/expense-reports/{reportId}");
          var row = Page.GetByRole(AriaRole.Row).Filter(new()
          {
              HasText = "Hôtel"
          });

          Page.Dialog += AcceptConfirmation;
          await row.GetByRole(AriaRole.Button, new()
          {
              Name = "Supprimer"
          }).ClickAsync();

      }

      /// <summary>Playwright dismisses the dialogs nobody handles: accept the deletion confirmation.</summary>
      private static void AcceptConfirmation(object? sender, IDialog dialog)
      {
          _ = dialog.AcceptAsync();
      }

      private async Task AddExpenseFromTheFormAsync(string date, string description, string amount)
      {
          await Page.GetByLabel("Date", new()
          {
              Exact = true
          }).FillAsync(date);
          await Page.GetByLabel("Description", new()
          {
              Exact = true
          }).FillAsync(description);
          await Page.GetByLabel("Montant (€)").FillAsync(amount);
          await Page.GetByLabel("Rue").FillAsync("8 quai du Port");
          await Page.GetByLabel("Code postal").FillAsync("13002");
          await Page.GetByLabel("Ville").FillAsync("Marseille");
          await Page.GetByRole(AriaRole.Button, new()
          {
              Name = "Ajouter"
          }).ClickAsync();
      }

      /// <summary>Creates an active user with a unique last name and their October 2025 report; returns the report id.</summary>
      private async Task<string> CreateReportAsync(string firstName)
      {
          var lastName = $"E2e{Guid.NewGuid().ToString("N")[..8]}";
          var user = await PostAsync("/api/v1/users", new
          {
              firstName,
              lastName,
              address = new
              {
                  street = "5 rue Victor Hugo", postalCode = "33000", city = "Bordeaux"
              },
              monthlyExpenseQuota = Quota,
          });
          var report = await PostAsync("/api/v1/expense-reports", new
          {
              userId = user.GetProperty("id").GetString(), year = 2025, month = 10
          });
          return report.GetProperty("id").GetString().ShouldNotBeNull();
      }

      private Task<JsonElement> AddExpenseThroughTheApiAsync(string reportId, string date, string description)
      {
          return PostAsync($"/api/v1/expense-reports/{reportId}/expenses", new
          {
              date,
              description,
              amount = 10m,
              billingAddress = new
              {
                  storeName = (string?)null, street = "1 rue de la Paix", postalCode = "75002", city = "Paris"
              },
          });
      }

      private async Task<JsonElement> PostAsync(string path, object body)
      {
          var response = await Page.APIRequest.PostAsync(path, new()
          {
              DataObject = body
          });
          response.Ok.ShouldBeTrue($"POST {path} answered {response.Status}");
          return (await response.JsonAsync()).ShouldNotBeNull();
      }
  }

  - **Modèle** : une dépense (`Expense`) appartient à une note de frais. Elle a une date, une description (50

    (`expense.date_outside_report_month`) ; une dépense au-delà du quota mensuel de l'utilisateur est refusée
    (`expense.quota_exceeded`) ; la note d'un utilisateur supprimé passe en lecture seule
    (`expense_report.deleted_user`).
  - **Concurrence** : chaque écriture d'une dépense verrouille la note (`SELECT … FOR UPDATE`), puis l'utilisateur
    (`FOR SHARE`), jusqu'à l'enregistrement. Deux ajouts simultanés pour la dernière place du quota donnent une
    dépense et un `422`, jamais deux dépenses ; un ajout voit la suppression de l'utilisateur faite en même temps. Une
    modification envoie la version lue (`If-Match`) : `412` si la dépense a changé entre-temps.
  - **API** sous `/v1/expense-reports/{reportId}/expenses` : liste paginée (par date), détail (avec `ETag`), ajout

    datées au format « mercredi 15 octobre 2025 ». Une note en lecture seule n'affiche ni formulaire ni actions sur
    ses dépenses. La liste des notes affiche le nombre de dépenses et le total de chacune.

    vérifie pas : elle ne peut pas changer de mois. Le quota appliqué est celui de l'utilisateur au moment de l'ajout.

  - Le montant va de 0,01 à 999 999,99 €, avec deux décimales au plus ; l'enseigne est facultative (100 caractères
