# Users Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the `User` model (postal address, monthly expense quota, active flag, soft delete), expose
create / read / update / activate / deactivate / delete under `/v1/users`, and give the administrator a French
management UI (paged list, create/edit form, activation toggle, delete with confirmation).

**Architecture:** Rich `User` entity and `Address` value object in `Domain`. One store per feature: `IUserStore`
in `Application`, implemented by `UserStore(AppDbContext)` in `Infrastructure`, serves the reads (`AsNoTracking`
projections) and the writes (`FindAsync` / `Add` / `SaveChangesAsync`); there is no repository and no
`IUnitOfWork`, because the `DbContext` already is the unit of work. One command handler per write use case.
Soft delete is an EF global query filter, so a deleted user answers 404 everywhere.

**Tech Stack:** .NET 10 (SDK 10.0.401) minimal APIs, EF Core 10 + Npgsql (Aspire 13.6.1), xUnit v3 on
Microsoft.Testing.Platform, Shouldly, NSubstitute, Reqnroll + Testcontainers + Respawn, Aspire.Hosting.Testing +
Playwright, Angular 22 + Nx 23 + Vitest.

**Spec:** [docs/superpowers/specs/2026-10-11-users-design.md](../specs/2026-10-11-users-design.md)

## Verified during planning

The spec's two "Risks to verify first" were spiked in a throwaway worktree of this repository, **with the repo's
analyzer set** (warnings as errors) and a real Postgres 18.3, so no spike task remains.

1. **Nested request validation**: .NET 10 minimal-API validation validates a nested record (`Address.PostalCode`,
   `Address.City`, a missing `Address`, `MonthlyExpenseQuota = 0` all answer `400` with a `ValidationProblemDetails`)
   **only when the request records are `public`**. With `internal` records the validation is skipped silently and
   invalid input answers `200`. CA1515 asks for `internal`, so request records live in
   `WebApi/Endpoints/Requests/` and `.editorconfig` relaxes CA1515 for that folder only (verified to build).
2. **`ComplexProperty` on Npgsql**: `Address` mapped with `ComplexProperty` generates the columns
   `Address_Street`, `Address_PostalCode` (`character(5)`), `Address_City`; the migration applies; users are
   materialized through `Address`'s validating constructor; `user.Address.City` translates in a projection; the
   query filter `DeletedAt == null` hides a soft-deleted row from the list.

Analyzer findings already folded into the code below:

- `User.Id` is a get-only property (`{ get; }`): a private setter is reported unused (S1144, RCS1170). EF then
  needs the key declared explicitly (`builder.HasKey(user => user.Id)`), otherwise it finds no primary key.
- Passing `nameof(x)` to an argument guard that has a `[CallerArgumentExpression]` parameter fails S3236. The
  domain's `Text.Required` guard therefore uses `[CallerArgumentExpression]` itself and throws manually.

Not verified during planning (write the code as given; the build or the test run tells you if an analyzer or an
API name needs a small fix): the Angular components, the Reqnroll step classes and the Playwright journeys.

## Spec deviations (decided while planning)

- **Postal code pattern** is `^[0-9]{5}$`, not `^\d{5}$`: in .NET `\d` also matches non-ASCII digits ("٧٥٠٠١"),
  which the domain rejects, so such input would answer 500 instead of 400.
- **No `FakeTimeProvider` package**: `DeleteUserHandler` tests substitute `TimeProvider` with NSubstitute
  (`GetUtcNow()` is virtual). One less dependency.
- **Ids are generated by the domain**: `User.Id` is initialized with `Guid.CreateVersion7()`, so a handler knows
  the id without a database round trip and acceptance steps know it before saving.
- **`UserStoreExtensions.GetAsync`** (internal to `Application`) wraps `FindAsync` and throws `NotFoundException`:
  the three handlers that change an existing user share it instead of repeating the null check.
- **`UserAddress`** (the read-side address) has its own file next to `UserDetails`.
- **Frontend details the spec leaves open**: the quota field of a new user starts empty; a save answered `404`
  (user deleted meanwhile) shows "Utilisateur introuvable.", any other failure "L'enregistrement a échoué.
  Veuillez réessayer."; deleting the last user of the last page shows the previous page instead of an empty one.

## Global Constraints

- SDK `10.0.401`; central package management, versions only in `Directory.Packages.props`. The only new package
  is `Microsoft.Extensions.DependencyInjection.Abstractions` `10.0.12`, referenced by `Application`.
- Do not add `Microsoft.NET.Test.Sdk` or `xunit.runner.visualstudio` (they bring VSTest back).
- `TreatWarningsAsErrors` stays on. No `#pragma warning disable`, no `<NoWarn>`. The only new rule relaxation is
  CA1515 for `backend/src/WebApi/Endpoints/Requests/**.cs`, in `.editorconfig` with a reason comment.
- Dependency rule unchanged: `Application` references `Domain` (and the DI abstractions) only — no EF Core, no
  ASP.NET Core. The architecture tests enforce it.
- Types consumed across projects are `public`; everything else `internal`. Request records are `public`
  (validation skips other types).
- Every method returning `Task`/`ValueTask` ends with `Async`, Reqnroll steps included (VSTHRD200). xUnit test
  methods use underscore sentences. Library code awaits with `.ConfigureAwait(false)`; test code does not.
- Limits, copied from the spec: first and last name ≤ 100 characters, street ≤ 200, city ≤ 100, all trimmed and
  non-blank; postal code exactly 5 ASCII digits; monthly quota a whole number ≥ 1 with no upper bound.
- English for code, Gherkin, commit messages and ProblemDetails. French for UI text and README "Mes Notes".
- Error contract: `400` validation, `404` unknown or deleted user (every route), no `422` in this slice.
- Run commands from the repository root. `dtk dotnet …` is a token-saving wrapper; plain `dotnet …` works too.
- Before each backend commit: `dotnet tool restore` (once), then
  `dotnet jb cleanupcode N2JSoft.slnx --profile="ReformatAndReorder" --verbosity=ERROR`. CI fails on any diff it

  ```csharp
  using System.Runtime.CompilerServices;

  namespace Domain;

  internal static class Text
  {
      /// <summary>Trims <paramref name="value" /> and checks it is neither blank nor longer than <paramref name="maxLength" />.</summary>
      public static string Required(
          string value,
          int maxLength,
          [CallerArgumentExpression(nameof(value))] string parameterName = "")
      {
          if (string.IsNullOrWhiteSpace(value))
          {
              throw new ArgumentException("The value must not be blank.", parameterName);
          }

          var trimmed = value.Trim();
          if (trimmed.Length > maxLength)
          {
              throw new ArgumentException($"The value must be at most {maxLength} characters.", parameterName);
          }

          return trimmed;
      }
  }
  ```

  ```csharp
  namespace Domain.ValueObjects;

  /// <summary>A French postal address: the street (with its number), a five-digit postal code and the city.</summary>
  public sealed record Address
  {
      public const int StreetMaxLength = 200;
      public const int CityMaxLength = 100;
      public const int PostalCodeLength = 5;

      public Address(string street, string postalCode, string city)
      {
          Street = Text.Required(street, StreetMaxLength);
          PostalCode = postalCode.Trim();
          if (PostalCode.Length != PostalCodeLength || !PostalCode.All(char.IsAsciiDigit))
          {
              throw new ArgumentException($"The postal code must be {PostalCodeLength} digits.", nameof(postalCode));
          }

          City = Text.Required(city, CityMaxLength);
      }

      public string Street { get; }
      public string PostalCode { get; }
      public string City { get; }
  }
  ```

  ```csharp
  using Domain.ValueObjects;

  namespace Domain.Entities;

  public sealed class User
  {
      public const int NameMaxLength = 100;

      /// <summary>Only <see cref="Create" /> and EF Core, which then sets the properties it loads, build users.</summary>
      private User()
      {
      }

      public Guid Id { get; } = Guid.CreateVersion7();
      public string FirstName { get; private set; } = string.Empty;
      public string LastName { get; private set; } = string.Empty;
      public Address Address { get; private set; } = null!;

      /// <summary>The most expenses the user may have in one calendar month (enforced when an expense is created).</summary>
      public int MonthlyExpenseQuota { get; private set; }

      /// <summary>Only active users can be assigned to an expense report.</summary>
      public bool IsActive { get; private set; }

      /// <summary>Set by a logical deletion; a deleted user is hidden from every query.</summary>
      public DateTimeOffset? DeletedAt { get; private set; }

      public static User Create(string firstName, string lastName, Address address, int monthlyExpenseQuota)
      {
          var user = new User
          {
              IsActive = true
          };
          user.UpdateDetails(firstName, lastName, address, monthlyExpenseQuota);
          return user;
      }

      /// <summary>Checks every detail before changing any, so a rejected update leaves the user as it was.</summary>
      public void UpdateDetails(string firstName, string lastName, Address address, int monthlyExpenseQuota)
      {
          ArgumentNullException.ThrowIfNull(address);
          ArgumentOutOfRangeException.ThrowIfLessThan(monthlyExpenseQuota, 1);
          var trimmedFirstName = Text.Required(firstName, NameMaxLength);
          var trimmedLastName = Text.Required(lastName, NameMaxLength);

          FirstName = trimmedFirstName;
          LastName = trimmedLastName;
          Address = address;
          MonthlyExpenseQuota = monthlyExpenseQuota;
      }

      public void Activate()
      {
          IsActive = true;
      }

      public void Deactivate()
      {
          IsActive = false;
      }

      public void Delete(DateTimeOffset now)
      {
          DeletedAt ??= now;
      }
  }
  ```

  ```csharp
  using Domain.Entities;
  using Domain.ValueObjects;
  using Microsoft.EntityFrameworkCore;
  using Microsoft.EntityFrameworkCore.Metadata.Builders;

  namespace Infrastructure.Persistence;

  internal sealed class UserEntityTypeConfiguration : IEntityTypeConfiguration<User>
  {
      public void Configure(EntityTypeBuilder<User> builder)
      {
          builder.ToTable("users");
          // Id is get-only, so EF Core does not discover it as the key by convention.
          builder.HasKey(user => user.Id);
          builder.Property(user => user.FirstName).HasMaxLength(User.NameMaxLength);
          builder.Property(user => user.LastName).HasMaxLength(User.NameMaxLength);
          builder.ComplexProperty(user => user.Address, address =>
          {
              address.Property(a => a.Street).HasMaxLength(Address.StreetMaxLength);
              address.Property(a => a.PostalCode).HasMaxLength(Address.PostalCodeLength).IsFixedLength();
              address.Property(a => a.City).HasMaxLength(Address.CityMaxLength);
          });
          // A deleted user is invisible to every query, so every read and update of one answers "not found".
          builder.HasQueryFilter(user => user.DeletedAt == null);
      }
  }
  ```

  ```csharp
  namespace AcceptanceTests.Support;

  /// <summary>One instance per scenario (Reqnroll context injection), disposed at the end of the scenario.</summary>
  public sealed class ApiDriver : IDisposable
  {
      private HttpClient _client = TestEnvironment.Factory.CreateClient();
      private HttpResponseMessage? _response;

      public HttpResponseMessage Response =>
          _response ?? throw new InvalidOperationException("No request has been sent yet.");

      public void Dispose()
      {
          _response?.Dispose();
          _client.Dispose();
      }

      public void UseDevelopmentEnvironment()
      {
          _client.Dispose();

      }

      public Task GetAsync(string path)
      {
          return SendAsync(HttpMethod.Get, path);
      }

      public async Task SendAsync(HttpMethod method, string path, JsonNode? body = null)
      {
          using var request = new HttpRequestMessage(method, new Uri(path, UriKind.Relative));
          if (body is not null)

              request.Content = JsonContent.Create(body);
          }

          _response?.Dispose();
          _response = await _client.SendAsync(request);
      }

      public async Task<T> ReadJsonAsync<T>()
          where T : class
      {
          var json = await Response.Content.ReadAsStringAsync();
          return JsonSerializer.Deserialize<T>(json, JsonSerializerOptions.Web).ShouldNotBeNull();
      }
  ```

  ```csharp
  using Application.Paging;
  using Application.Users;
  using Domain.Entities;
  using Infrastructure.Persistence;
  using Microsoft.EntityFrameworkCore;

  namespace Infrastructure.Users;

  internal sealed class UserStore(AppDbContext dbContext) : IUserStore
  {
      public async Task<PagedResult<UserSummary>> ListAsync(PageRequest request, CancellationToken cancellationToken)
      {
          var users = dbContext.Set<User>().AsNoTracking();
          var totalCount = await users.CountAsync(cancellationToken).ConfigureAwait(false);
          var items = await users
              .OrderBy(user => user.LastName)
              .ThenBy(user => user.FirstName)
              // Users sharing a name keep the same order from one page to the next.
              .ThenBy(user => user.Id)
              .Skip(request.Skip)
              .Take(request.PageSize)
              .Select(user => new UserSummary(
                  user.Id,
                  $"{user.FirstName} {user.LastName}",
                  user.Address.City,
                  user.MonthlyExpenseQuota,
                  user.IsActive))
              .ToListAsync(cancellationToken)
              .ConfigureAwait(false);

          return new PagedResult<UserSummary>(items, request.Page, request.PageSize, totalCount);
      }

      public Task<UserDetails?> GetDetailsAsync(Guid id, CancellationToken cancellationToken)
      {
          return dbContext.Set<User>()
              .AsNoTracking()
              .Where(user => user.Id == id)
              .Select(user => new UserDetails(
                  user.Id,
                  user.FirstName,
                  user.LastName,
                  new UserAddress(user.Address.Street, user.Address.PostalCode, user.Address.City),
                  user.MonthlyExpenseQuota,
                  user.IsActive))
              .SingleOrDefaultAsync(cancellationToken);
      }
  }
  ```

  ```ts
      }
      @if (page(); as page) {
        @if (page.items.length > 0) {
          <table class="w-full text-left">
            <thead>
              <tr>
                <th>Nom</th>
                <th>Ville</th>
                <th>Quota mensuel</th>
                <th>Statut</th>
                <th>Actions</th>
              </tr>
            </thead>
            <tbody>
              @for (user of page.items; track user.id) {
                <tr>
                  <td>{{ user.name }}</td>
                  <td>{{ user.city }}</td>
                  <td>{{ user.monthlyExpenseQuota }}</td>
                  <td>{{ user.isActive ? 'Actif' : 'Inactif' }}</td>
                  <td class="flex gap-3">
                    <a [routerLink]="['/users', user.id, 'edit']" class="underline">Modifier</a>
                    <button type="button" (click)="toggle(user)">
                      {{ user.isActive ? 'Désactiver' : 'Activer' }}
                    </button>
                    <button type="button" (click)="remove(user)">Supprimer</button>
                  </td>
                </tr>
              }
            </tbody>
          </table>
          <nav aria-label="Pagination" class="mt-4 flex items-center gap-4">
            <button type="button" [disabled]="page.page <= 1" (click)="load(page.page - 1)">
              Précédent
            </button>
            <span>Page {{ page.page }} sur {{ pageCount() }}</span>
            <button type="button" [disabled]="page.page >= pageCount()" (click)="load(page.page + 1)">
              Suivant
            </button>
          </nav>
        } @else {
          <p>Aucun utilisateur.</p>
        }
      } @else if (!failed()) {
        <p>Chargement…</p>
      }
    `,
  })
  export default class UserListPage {
    private readonly api = inject(UsersApi);
    protected readonly page = signal<PagedResult<UserSummary> | undefined>(undefined);
    protected readonly failed = signal(false);
    protected readonly actionFailed = signal(false);
    protected readonly pageCount = computed(() => {
      const page = this.page();
      return page ? Math.max(1, Math.ceil(page.totalCount / page.pageSize)) : 1;
    });

    constructor() {
      this.load(1);
    }

    protected load(pageNumber: number): void {
      this.api.list(pageNumber, pageSize).subscribe({
        next: (page) => {
          // The last user of the last page is gone: show the page before rather than an empty one.
          if (page.items.length === 0 && page.page > 1) {
            this.load(page.page - 1);
            return;
          }
          this.page.set(page);
          this.failed.set(false);
        },
        error: () => this.failed.set(true),
      });
    }

    protected toggle(user: UserSummary): void {
      this.run(user.isActive ? this.api.deactivate(user.id) : this.api.activate(user.id));
    }

    protected remove(user: UserSummary): void {
      if (window.confirm(`Supprimer l'utilisateur ${user.name} ?`)) {
        this.run(this.api.delete(user.id));
      }
    }

    private run(action: Observable<void>): void {
      this.actionFailed.set(false);
      action.subscribe({
        next: () => this.load(this.page()?.page ?? 1),
        error: () => this.actionFailed.set(true),
      });
    }
  }
  ```

  ```ts
  import { HttpErrorResponse } from '@angular/common/http';
  import { Component, inject, signal } from '@angular/core';
  import {
    AbstractControl,
    NonNullableFormBuilder,
    ReactiveFormsModule,
    ValidationErrors,
    Validators,
  } from '@angular/forms';
  import { ActivatedRoute, Router, RouterLink } from '@angular/router';
  import { Observable } from 'rxjs';
  import { SaveUser } from './user-details';
  import { UsersApi } from './users.api';

  type Field =
    | 'firstName'
    | 'lastName'
    | 'street'
    | 'postalCode'
    | 'city'
    | 'monthlyExpenseQuota';

  /** Like Validators.required, but text made only of spaces is missing too: the API would trim it to nothing. */
  function requiredText(control: AbstractControl<string>): ValidationErrors | null {
    return control.value.trim() === '' ? { required: true } : null;
  }

  function isNotFound(error: unknown): boolean {
    return error instanceof HttpErrorResponse && error.status === 404;
  }

  function saveErrorMessage(error: unknown): string {
    if (isNotFound(error)) {
      return 'Utilisateur introuvable.';
    }
    if (error instanceof HttpErrorResponse && error.status === 400) {
      return 'Les informations saisies sont invalides.';
    }
    return "L'enregistrement a échoué. Veuillez réessayer.";
  }

  @Component({
    selector: 'app-user-form-page',
    imports: [ReactiveFormsModule, RouterLink],
    template: `
      <h1 class="mb-4 text-2xl font-semibold">{{ title }}</h1>
      @if (error(); as message) {
        <p role="alert">{{ message }}</p>
      }
      @if (loaded()) {
        <form [formGroup]="form" (ngSubmit)="save()" novalidate class="flex max-w-md flex-col gap-2">
          <label for="firstName">Prénom</label>
          <input id="firstName" formControlName="firstName" />
          @if (errorFor('firstName'); as message) {
            <p class="field-error text-sm text-red-700">{{ message }}</p>
          }

          <label for="lastName">Nom</label>
          <input id="lastName" formControlName="lastName" />
          @if (errorFor('lastName'); as message) {
            <p class="field-error text-sm text-red-700">{{ message }}</p>
          }

          <label for="street">Rue</label>
          <input id="street" formControlName="street" />
          @if (errorFor('street'); as message) {
            <p class="field-error text-sm text-red-700">{{ message }}</p>
          }

          <label for="postalCode">Code postal</label>
          <input id="postalCode" formControlName="postalCode" inputmode="numeric" />
          @if (errorFor('postalCode'); as message) {
            <p class="field-error text-sm text-red-700">{{ message }}</p>
          }

          <label for="city">Ville</label>
          <input id="city" formControlName="city" />
          @if (errorFor('city'); as message) {
            <p class="field-error text-sm text-red-700">{{ message }}</p>
          }

          <label for="monthlyExpenseQuota">Quota mensuel de dépenses</label>
          <input id="monthlyExpenseQuota" type="number" min="1" step="1" formControlName="monthlyExpenseQuota" />
          @if (errorFor('monthlyExpenseQuota'); as message) {
            <p class="field-error text-sm text-red-700">{{ message }}</p>
          }

          <div class="mt-2 flex gap-4">
            <button type="submit" [disabled]="saving()">Enregistrer</button>
            <a routerLink="/users" class="underline">Annuler</a>
          </div>
        </form>
      } @else if (!error()) {
        <p>Chargement…</p>
      }
    `,
  })
  export default class UserFormPage {
    private readonly api = inject(UsersApi);
    private readonly router = inject(Router);
    /** Null on /users/new. */
    private readonly id = inject(ActivatedRoute).snapshot.paramMap.get('id');
    protected readonly title = this.id === null ? 'Nouvel utilisateur' : "Modifier l'utilisateur";
    protected readonly loaded = signal(this.id === null);
    protected readonly saving = signal(false);
    protected readonly error = signal<string | null>(null);

    private readonly formBuilder = inject(NonNullableFormBuilder);
    protected readonly form = this.formBuilder.group({
      firstName: ['', [requiredText, Validators.maxLength(100)]],
      lastName: ['', [requiredText, Validators.maxLength(100)]],
      street: ['', [requiredText, Validators.maxLength(200)]],
      postalCode: ['', [Validators.required, Validators.pattern(/^[0-9]{5}$/)]],
      city: ['', [requiredText, Validators.maxLength(100)]],
      monthlyExpenseQuota: this.formBuilder.control<number | null>(null, [
        Validators.required,
        Validators.min(1),
        Validators.pattern(/^[0-9]+$/),
      ]),
    });

    constructor() {
      if (this.id !== null) {
        this.api.get(this.id).subscribe({
          next: (user) => {
            this.form.setValue({
              firstName: user.firstName,
              lastName: user.lastName,
              street: user.address.street,
              postalCode: user.address.postalCode,
              city: user.address.city,
              monthlyExpenseQuota: user.monthlyExpenseQuota,
            });
            this.loaded.set(true);
          },
          error: (error: unknown) =>
            this.error.set(
              isNotFound(error) ? 'Utilisateur introuvable.' : "Impossible de charger l'utilisateur."
            ),
        });
      }
    }

    protected errorFor(field: Field): string | null {
      const control = this.form.controls[field];
      if (control.valid || !control.touched) {
        return null;
      }
      if (control.hasError('required')) {
        return 'Ce champ est obligatoire.';
      }
      if (control.hasError('maxlength')) {
        return `${control.getError('maxlength').requiredLength} caractères au maximum.`;
      }
      return field === 'postalCode'
        ? 'Le code postal doit comporter 5 chiffres.'
        : 'Le quota doit être un nombre entier supérieur ou égal à 1.';
    }

    protected save(): void {
      if (this.form.invalid) {
        this.form.markAllAsTouched();
        return;
      }
      const value = this.form.getRawValue();
      const user: SaveUser = {
        firstName: value.firstName,
        lastName: value.lastName,
        address: { street: value.street, postalCode: value.postalCode, city: value.city },
        monthlyExpenseQuota: value.monthlyExpenseQuota ?? 0,
      };
      const request: Observable<unknown> =
        this.id === null ? this.api.create(user) : this.api.update(this.id, user);

      this.saving.set(true);
      this.error.set(null);
      request.subscribe({
        next: () => {
          void this.router.navigateByUrl('/users');
        },
        error: (error: unknown) => {
          this.saving.set(false);
          this.error.set(saveErrorMessage(error));
        },
      });
    }
  }
  ```
